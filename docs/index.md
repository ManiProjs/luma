## Two ways to work

**Code** is the hands-on workspace for inspecting projects, editing files, running commands, and reviewing changes. **Teammates** are persistent agents with their own conversations, memory, skills, and background tasks.

Both run on the same Luma Core. Pick the workflow that fits the job; the docs explain the moving parts.
